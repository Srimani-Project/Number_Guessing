# Number Guessing Game

This is a simple number guessing game written in Python. The computer randomly selects a number, and the player tries to guess it.

## Features

- Random number generation
- User input for guesses
- Feedback on whether the guess is too high or too low
- Game loop until the correct guess is made

## Requirements

- Python 3.x

## How to Play

1. Run the `number_guessing_game.py` script.
2. The computer will randomly select a number between a specified range (e.g., 1 to 100).
3. Enter your guess.
4. The game will tell you if your guess is too high or too low.
5. Keep guessing until you find the correct number.
